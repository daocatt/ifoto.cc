# 你画我猜 (Whiteboard Game) 全新架构升级与全栈开发计划文档

## 一、 系统愿景与核心架构

本项目将进行全面的架构升级，打造一套兼具 **「极简本地单机即开即玩」** 与 **「企业级非本地线上多租户账户协同」** 双模式的现代化你画我猜平台。

### 1.1 技术选型
- **Web 服务端框架**：`Hono`（轻量、高性能、模块化路由与中间件生态）
- **数据库与持久层**：`PostgreSQL` + `Drizzle ORM` + `drizzle-kit`（强类型安全、轻量高效、规范的 Migrations 迁移机制）
- **实时协同**：`WebSocket` 实时游戏房间管道 + Excalidraw 笔迹流协同
- **前端架构**：`React 19` + `TypeScript` + `TailwindCSS v4` + `Lucide Icons`
- **头像系统**：`DiceBear Voxel Art`（纯本地离线内置 20+ 款精美体素风格头像，杜绝外部网络依赖）
- **容器与部署**：`Docker Compose`（含 App 服务容器与 PostgreSQL 容器、环境变量注入、数据卷持久化）

## 二、 双模式运行机制 (Dual-Mode Architecture)

通过根目录 `.env` 配置环境变量 `APP_MODE` 自动切换运行逻辑：

```ini
# .env 示例
APP_MODE=online                # local (本地模式) 或 online (线上/非本地模式)
PORT=3000
DATABASE_URL=postgres://whiteboard_user:whiteboard_secret_password@postgres:5432/whiteboard_db
APP_DOMAIN=https://draw.example.com
ALLOW_REGISTER=true           # 是否开放用户公开注册
JWT_SECRET=super_secret_jwt_key_here_at_least_32_chars
```

### 2.1 本地模式 (Local Mode)
- **特点**：无数据库依赖、免注册登录、全内网即开即玩。
- **页面流程**：
  1. **首页**：超大视觉标题「你画我猜」，居中操作按钮「立即开启」。
  2. **独立选房/身份页**：挑选 20 款离线体素头像、填写昵称、选择房间（🎨 你画我猜 / 🔤 英语猜猜看），进入游戏。
  3. **游戏房间**：纯本地协同画板与计分。

### 2.2 线上/非本地模式 (Online Mode)
- **特点**：基于 PostgreSQL + Hono 的完整用户中心、权限控制、个人房间与比赛历史统计。
- **首次部署向导**：检测数据库无管理员时，自动引导进入 `/init-admin` 超级管理员初始化页面（强制强密码校验）。
- **页面流程**：
  1. **首页**：大标题「你画我猜」+「立即开启」/「进入大厅」。
  2. **登录 / 注册页**：邮箱、唯一昵称、密码（支持关闭注册开关）。
  3. **大厅与公开房间列表**：
     - 公开房间列表（展示所有公开开启的房间、当前人数、创建者、开放时间）。
     - 我的专属房间（每个注册用户可创建 1 个自定义房间，支持设置简单密码、开放时段、开启/关闭状态，生成专属分享链接与二维码）。
     - 上次玩过的历史房间快捷入口。
  4. **个人主页 & 战绩**：
     - 展示用户头像、唯一昵称、历史参赛记录（房间名称、比赛局数、历史总得分与胜率）。
     - 支持设置战绩「公开 / 仅自己可见」。
  5. **个人设置中心**：
     - 更换本地体素头像、修改唯一昵称、修改密码。
  6. **游戏房间**：
     - 专属房间支持密码校验、邀请链接直达（未登录者登录后自动重定向入房）。
     - 房间定时关闭检测（到达非开放时间自动锁定并优雅清空在线人员）。

## 三、 数据库模型设计 (Drizzle Schema)

规范放置在 `src/db/schema.ts`：

### 3.1 用户表 (`users`)
| 字段名 | 类型 | 约束 | 描述 |
|---|---|---|---|
| `id` | `uuid` | PK, 默认 gen_random_uuid() | 用户唯一标识 |
| `email` | `varchar(255)` | UNIQUE, NOT NULL | 登录邮箱 |
| `name` | `varchar(50)` | UNIQUE, NOT NULL | 全局唯一昵称 |
| `password_hash` | `text` | NOT NULL | 加盐哈希密码 (bcrypt/scrypt) |
| `avatar_key` | `varchar(50)` | NOT NULL | 绑定的体素头像标识符 (voxel_01 ~ voxel_20) |
| `role` | `varchar(20)` | DEFAULT 'user' | 角色: 'admin' (超管) / 'user' |
| `is_stats_public` | `boolean` | DEFAULT true | 个人战绩是否对所有人公开 |
| `created_at` | `timestamp` | DEFAULT now() | 注册时间 |
| `updated_at` | `timestamp` | DEFAULT now() | 资料更新时间 |

### 3.2 自定义房间表 (`rooms`)
| 字段名 | 类型 | 约束 | 描述 |
|---|---|---|---|
| `id` | `varchar(64)` | PK | 房间唯一 slug (如 my-room-abc) |
| `owner_id` | `uuid` | FK(users.id), UNIQUE | 房主ID (每个用户最多拥有1个专属房间) |
| `name` | `varchar(100)` | NOT NULL | 房间名称 |
| `type` | `varchar(20)` | DEFAULT 'draw' | 房间类型: 'draw' (中文) / 'english' (英文) |
| `password_hash` | `varchar(255)` | NULLABLE | 房间入房简单密码 (选填) |
| `is_open` | `boolean` | DEFAULT true | 房主手动开关状态 |
| `open_start_time` | `time` | NULLABLE | 每天定时开放起始时间 (如 "09:00") |
| `open_end_time` | `time` | NULLABLE | 每天定时开放结束时间 (如 "22:00") |
| `is_public` | `boolean` | DEFAULT true | 是否在大厅公开房间列表中展示 |
| `created_at` | `timestamp` | DEFAULT now() | 创建时间 |

### 3.3 比赛计分与对局历史表 (`game_records`)
| 字段名 | 类型 | 约束 | 描述 |
|---|---|---|---|
| `id` | `uuid` | PK, 默认 gen_random_uuid() | 记录标识 |
| `user_id` | `uuid` | FK(users.id), NOT NULL | 参赛玩家 ID |
| `room_id` | `varchar(64)` | NOT NULL | 所在房间 ID |
| `room_name` | `varchar(100)` | NOT NULL | 记录时的房间名称 |
| `round_count` | `integer` | DEFAULT 1 | 参与对局数 |
| `score` | `integer` | DEFAULT 0 | 本场比赛最终得分 |
| `played_at` | `timestamp` | DEFAULT now() | 比赛完成时间 |

## 四、 本地体素头像系统 (DiceBear Voxel Art)

- 严禁外部图片直连，所有头像 SVG 代码全部本地模块化存储在 `src/constants/voxelAvatars.ts`。
- 精心挑选和配置 **24 款经典体素造型**：
  - 性别与年龄：男孩、女孩、职业青年、老年长者、呆萌搞怪、极客少年等各 6 款。
  - 特征：多款不同发型（短发、波浪卷、丸子头、帽子）、多样面部表情（微笑、眨眼、酷墨镜、大笑）。
- 提供 `<VoxelAvatar avatarKey={key} size={size} />` 统一渲染组件。

| **Phase 4** | **前端路由与多页面重构**：<br>1. 极简首页 (`HomePage.tsx`)<br>2. 独立本地选房页 (`LocalLobbyPage.tsx`)<br>3. 线上大厅与公开房间列表 (`OnlineLobbyPage.tsx`)<br>4. 登录/注册/超管初始化页<br>5. 个人主页与设置中心<br>6. 房间分享与二维码弹窗 (`ShareRoomModal.tsx`) | `src/pages/*`, `src/components/Auth/*`, `src/components/Lobby/*` |

| **Phase 6** | **构建验证、白名单打包与提交**：执行 Drizzle Migrations，生产编译校验，符合打包标准生成 `whiteboard.zip` | Git 提交记录, `whiteboard.zip` |
